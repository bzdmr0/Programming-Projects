# Drop Dead

## Assignment Context

This is the second assignment of the C Programming course.

## Project Overview

Drop Dead is a dice game (originally created by United States soldiers as an alternative to poker). The assignment is to implement a playable Drop Dead game between a human player and the computer.

## Purpose

This project is designed to practice:
- Sequence
- Selection
- Repetition

It also emphasizes functional decomposition by requiring the solution to be split into cohesive, loosely coupled functions.
