# Programming Projects

This repository contains a collection of university programming assignments and course projects.

## What you'll find here

The projects span multiple programming languages and topics, including:

- C
- C++
- Python
- MATLAB

## Project themes

Across the repository, the assignments explore a range of computer science and software development topics such as:

- Game programming
- Image processing
- Image classification
- Campus management systems
- Multimodal machine learning

## Repository purpose

The goal of this repository is to showcase coursework completed during university and to keep the projects organized in one place. Some projects are small assignments, while others are more detailed implementations built around specific course requirements.

## Contents

Each folder in the repository typically represents a separate assignment or project. In most cases, the main implementation, supporting files, and project-specific documentation can be found inside the corresponding directory.

## Notes

Because these are university assignments, some projects may focus more on demonstrating concepts than on polished production-ready design. As a result, you may see code written for experimentation, academic evaluation, or proof-of-concept purposes.
