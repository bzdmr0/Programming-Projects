# University Campus Management System

## Assignment Context

This is the second assignment of the Programming Language Concepts course.

## Project Overview

This assignment requires implementing several C++ classes to model a university campus with multiple buildings.

## Purpose

The project aims to build a storage system for campus data and support generating different report types for users.

## Implementation Requirements

- Put each class declaration in a separate header (`.h`) file.
- Implement member methods in separate source (`.cpp`) files.
